# Rishitha — Backend & Data Platforms

A static, accessible portfolio with a developer-workstation design, visible navigation, and optional terminal commands. Built from the MIT-licensed [PythonToGo terminal portfolio template](https://github.com/PythonToGo/terminal-portfolio-template).

Start with [CUSTOMIZATION.md](CUSTOMIZATION.md) for editing content, previewing, verification, and publication preparation. The detailed implementation proposal is in `../PORTFOLIO_CUSTOMIZATION_PLAN.md`.

```sh
npm ci
npm run dev
```

Local preview: http://127.0.0.1:4030. Edit `terminal-config.js`, then `npm run build` and refresh. Deployable output is `dist/`. No backend or production npm dependencies are required.

The original generator and legacy styles are reference material and are not included in the production build.
